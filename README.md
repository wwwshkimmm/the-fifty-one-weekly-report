# THE FIFTY ONE · 주간보고 자동화 플랫폼

## 프로젝트 개요

**주간보고 자동화 플랫폼**은 매주 반복되는 주간보고 메일 작성 업무를 자동화하는 웹 애플리케이션입니다.  
사용자가 키워드 단위로 간략히 입력한 작업과 근태 일정을 **AI 문장 정제**로 프론트엔드 실무 톤의 비즈니스 문장으로 변환하고, 정해진 메일 양식에 맞춘 주간보고 본문을 자동 생성합니다. 제출 완료 시 **LocalStorage**에 이력이 저장되며, 누적된 보고 데이터를 분석해 **나의 업무 리포트**로 키워드 비중과 업무 패턴을 시각화합니다.

---

## 추천 설명

주간보고 자동화 플랫폼은, 작업과 근태 정보를 입력하면 AI가 문장을 다듬고 주간보고 메일 본문을 자동 생성해주는 웹 앱입니다.

이 프로젝트는 서버 없이 브라우저에서 동작하는 단일 HTML 웹 앱입니다. Vue 3로 사용자 입력과 화면 상태를 관리하고, Tailwind CSS로 UI를 구성했습니다. 루틴 업무 원클릭 등록, AI 문장 정제, 주간보고 생성·복사, 제출 완료 처리, 이력 관리, 업무 키워드 리포트까지 한 화면에서 처리됩니다. 매주 목요일 오전 10시 제출 기한까지 남은 시간을 실시간으로 안내하여 보고 누락을 방지하며, 제출 완료 시 이력이 자동 저장됩니다. 반복적인 주간보고 작성 업무를 자동화하여 보고서 작성 시간을 단축하고, 제출 기한 준수율을 높이는 업무 효율화 도구입니다.

## 프로젝트 설명

이 프로젝트는 **HTML 단일 파일 기반의 클라이언트 사이드 웹 애플리케이션**입니다.

- **HTML** — 화면 구조 및 레이아웃 정의
- **Vue 3** — 반응형 UI 상태 관리, 사용자 인터랙션 처리
- **Tailwind CSS** — 컴포넌트 스타일링 및 반응형 디자인
- **JavaScript** — Vue 로직 및 비즈니스 로직 구현 언어
- **LocalStorage** — 제출 이력 저장 및 업무 키워드 통계 분석

별도의 빌드 도구(Vite, Webpack 등)나 백엔드 서버 없이 CDN을 통해 Vue 3와 Tailwind CSS를 로드하여 즉시 실행 가능한 구조로 개발했습니다. 보고서 생성은 브라우저 메모리에서 처리되며, 제출 이력과 업무 통계는 LocalStorage에 저장되는 경량 정적 페이지입니다.

## 기능

### 1. 금주 작업 등록

- 수행한 업무(과제명)를 입력하고 목록에 추가·삭제
- Enter 키 또는 버튼 클릭으로 빠른 등록
- 등록된 작업 수 실시간 표시

### 2. 루틴 업무 빠른 등록

- 자주 반복하는 업무를 원클릭으로 `tasks` 리스트에 즉시 추가
- 기본 루틴 버튼: **긴급배포**, **개발/구현**, **공지사항 등록**
- 중복 등록 시 안내 토스트 표시

### 3. 근태·휴가 일정 등록

- 연차, 반차 등 근태 일정을 별도 섹션에서 관리
- 체크박스로 근태 모드 on/off 전환
- 보고서 생성 시 `[기타 특이사항]` 섹션에 자동 반영

### 4. AI 기반 주간보고 문장 정제

- 키워드 단위 입력(예: `고객지원 업무`, `긴급배포`)을 프론트엔드 실무 톤 문장으로 자동 변환
- `refineTasksWithAi` → `mockAiProcess` / `callCursorApi` 연동 구조 지원
- API 키 없이도 mock 모드로 시연·검증 가능
- 키워드별 정제 규칙: 고객지원, GEO, 배포, 장애, 수정, 이벤트, 개발/구현, API 연동 등

### 5. 주간보고 텍스트 자동 생성

- AI 정제된 작업·근태 정보를 기반으로 메일 본문 자동 작성
- 연도·월·주차, 담당자 정보 등 고정 양식 자동 삽입
- `[이번주 주요 이슈]`, `[기타 특이사항]` 형식으로 구조화된 출력

### 6. 원클릭 메일 복사

- 생성된 텍스트를 클립보드에 한 번에 복사
- 복사 완료 시 토스트 알림 표시
- 메일 클라이언트에 바로 붙여넣기 가능

### 7. 제출 기한 카운트다운 및 제출 완료 처리

- 매주 **목요일 오전 10:00** 제출 기한 기준 실시간 카운트다운
- 상단 배너에 남은 시간(시·분·초) 표시
- **주간보고 제출 완료** 클릭 시 배너가 **정상 제출 완료** 상태로 전환 (`isSubmitted`)

### 8. 지난 주차 보고 이력 관리

- LocalStorage 기반으로 제출 이력 자동 저장·유지 (새로고침 후에도 유지)
- 이력 목록에서 **내용 보기** 팝업으로 과거 보고서 전문 조회·복사
- 체크박스 선택 후 **선택 삭제**로 이력 관리

### 9. 나의 업무 리포트 (키워드 통계 대시보드)

- 화면 하단에 LocalStorage 저장 이력 텍스트 기반 업무 분석 리포트 표시
- 모든 업무는 **고객지원** 프로젝트 내 프론트엔드 실무를 전제로 하며, 통계는 그 하위 실무 유형을 분류
- 최근 4건 보고서를 분석해 카테고리별 키워드 등장 횟수 집계
- **요약 문장** 자동 생성 (예: "김송희 님은 최근 4주간 [개발/구현] 업무를 가장 많이 수행하셨으며, [배포/긴급] 비중이 그 뒤를 이었습니다.")
- **나의 업무 키워드** 태그 클라우드 (`#배포`, `#개발`, `#공지` 등)
- **카테고리별 업무 비중** Tailwind 막대 게이지 바 차트 (횟수·%)
- 이력 없을 시: "과거 이력이 누적되면 업무 통계가 시각화됩니다" 안내

**분석 키워드 카테고리** (고객지원 프로젝트 내 실무 유형)


| 카테고리  | 매칭 키워드                   |
| ----- | ------------------------ |
| 서버/점검 | 서버, 점검                   |
| 회의/협업 | 회의, 미팅, 싱크업, 협업          |
| 배포/긴급 | 배포, 긴급, 장애, 핫픽스          |
| 개발/구현 | 개발, 구현, UI, 화면, 컴포넌트, 코드 |
| 이벤트   | 이벤트, 프로모션, 배너            |
| 모니터링  | 모니터링, 모니터                |
| 공지    | 공지                       |


> **고객지원**은 본인이 수행 중인 프로젝트의 큰 틀(상위 업무 영역)이며, 위 카테고리는 그 안에서의 세부 실무 유형을 분류합니다.

## 성과 시나리오

KPI·성과목표 제출 시 아래 시나리오로 핵심 성과를 증빙할 수 있습니다.

### 1. AI 기반 프로세스 개선 사례 증빙 (`refineTasksWithAi` 함수)

사용자가 키워드 단위(`고객지원 업무`, `긴급배포`)로 대충 타이핑하더라도, **AI 문장 융합 알고리즘**이 프론트엔드 실무에 맞는 프로페셔널 비즈니스 문장으로 정제하여 텍스트를 출력합니다.

> **어필 포인트:** 단순히 텍스트 양식에 변수를 끼워 넣는 하드코딩 툴이 아니라, **행정 업무의 패러다임을 바꾼 실제 AI 개선 사례**로 포지셔닝할 수 있습니다.

**증빙 예시**


| 입력 (개조식) | AI 정제 결과                                       |
| -------- | ---------------------------------------------- |
| 고객지원 업무  | 고객지원 관련 화면 이슈 확인 및 프론트엔드 코드 수정·배포 반영           |
| 긴급배포     | 프론트엔드 빌드 및 스테이징·운영 환경 배포, 배포 후 화면·API 연동 동작 확인 |
| 버그 수정    | 버그 수정 건 UI·로직 원인 분석 후 프론트엔드 코드 수정 및 스테이징 검증 완료 |


### 2. 업무 보고 준수율 100% 달성 및 지속 가능성 증빙 (LocalStorage 이력 목록)

무거운 DB 서버 연결 없이도, 브라우저가 기억하는 **LocalStorage** 기술을 노코드 사상에 맞춰 최적화 이식했습니다. 사용자가 마감 전에 **주간보고 제출 완료** 버튼을 누르면 배너가 **정상 제출 완료** 상태로 활성화되며 정시 제출 데이터 인지를 돕고, 해당 본문은 **지난 주차 보고 이력**에 차곡차곡 안전하게 쌓입니다.

> **어필 포인트:** 차주 계획을 짤 때 과거 데이터를 매번 메일함에서 뒤질 필요 없이 **내 앱 안에서 영구적으로 이력을 추적 및 조회**할 수 있어 행정 리소스를 획기적으로 줄여줍니다.

**증빙 흐름**

1. 작업 입력 (또는 루틴 업무 원클릭 등록) → AI 문장 정제 → 보고서 생성
2. 제출 완료 클릭 → 배너 **정상 제출 완료** 전환
3. LocalStorage 자동 저장 → 새로고침 후에도 이력 유지
4. 이력 **내용 보기** 팝업으로 과거 보고서 즉시 조회

### 3. 데이터 기반 업무 인사이트 증빙 (나의 업무 리포트)

누적된 주간보고 텍스트를 태그 기반으로 분석하여, 사용자가 **어떤 유형의 업무를 가장 많이 수행했는지** 한눈에 파악할 수 있습니다.

> **어필 포인트:** 단순 보고 자동화를 넘어, **개인 업무 패턴을 데이터로 시각화**하여 성과 회고·업무 계획 수립에 활용할 수 있습니다.

**증빙 예시**

- 요약: "김송희 님은 최근 4주간 [고객지원] 업무를 가장 많이 수행하셨으며, [회의/협업] 비중이 그 뒤를 이었습니다."
- 태그 클라우드: `#고객지원` `#배포` `#개발` 등 빈도별 시각화
- 바 차트: 카테고리별 업무 비중(%) 막대 게이지

## 라이선스 및 비고

- 내부 업무용 도구로 제작
- 보고서 양식(인사말, 담당자명 등)은 `index.html` 내 `buildReportText` 함수에서 수정 가능
- AI mock 키워드 규칙은 `expandTaskToBusinessTone` 함수에서 추가·수정 가능
- 업무 리포트 분석 카테고리는 `KEYWORD_CATEGORIES` 상수에서 관리
- Cursor API 실연동 시 `AI_CONFIG`에서 `useMock: false` 및 `apiKey` 설정
